## Project Structure

- **`FastF1_Project1.ipynb`** — This is the **main project notebook** and the culmination of our work in this repository. It contains the final models, analysis, and results.

- All other notebooks (`F1Canada2025.ipynb`, `F1Dutch2025.ipynb`, `FastF1_Project.ipynb`, `compare.ipynb`, `prediction1.py`, `prediction2.py`, `prediction3.ipynb`, ..., `prediction9.ipynb`) were **experimental** and used during the development process to refine our approach, validate models, or explore different methodologies.

- **Note**: Before running the notebooks or scripts, create a folder named `f1_cache` inside the project directory.
